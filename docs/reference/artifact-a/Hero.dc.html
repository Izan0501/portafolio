P/01 · Producción

Nave24 Stock

MONOLITO + TIEMPO REAL · SUPABASE // DOCKER

Inventario de depósito en tiempo real: niveles de stock, movimientos y umbrales de reposición en varias ubicaciones.

El desafío: varias terminales escriben sobre los mismos conteos a la vez, y ninguna unidad puede contarse dos veces.

La solución: cada terminal registra movimientos que se difunden al instante con Supabase Realtime; el stock se actualiza en todas las pantallas y avisa cuando baja del umbral.

  • React
  • Vite
  • TypeScript
  • FastAPI
  • PostgreSQL
  • Supabase
  • Docker

P/02 · En desarrollo

VeeBot SaaS

MICROSERVICIOS · STAGING // CI/CD PIPELINE

SaaS de reclutamiento multi-tenant: un pipeline de IA puntúa, compara y entrevista cada CV con Gemini 2.5 Flash.

El desafío: aislar el pool de talento de cada agencia mientras la inferencia escala por separado bajo carga.

La solución: datos aislados por tenant, scoring con IA, búsqueda semántica en Pinecone y un gemelo digital que responde preguntas sobre cada CV.

  • React
  • FastAPI
  • MongoDB
  • Pinecone
  • Gemini 2.5 Flash

P/03 · Producción

Estudio Zanacchi

SPA / CSR · VERCEL EDGE // CDN GLOBAL

Sitio institucional y de captación para un estudio de derecho penal y del consumidor, con sedes en Tucumán y Catamarca.
